# Synthetic baffle dataset v1

Generated by `scripts/generate_dataset.py` (GitHub Actions workflow `generate-dataset`), published
as release assets of this repository (`dataset-v1`): ten geometry shards of 10 000 samples
(`shard_00.zip` to `shard_09.zip`, about 500 MB each) and physics-labelled shards
(`shard_00_physics.zip`, ...) with inflated states. A 100-sample slice is committed under
`neural/data/sample_100/` for tests and format reference.

Every shard is reproducible from its seed (`manifest.json`: base_seed, shard, workers); sample
ids are global (shard x n + i), and the train/val/test split is a deterministic 80/10/10 hash of
the id (`dataset_io.split_of`), so results are comparable across machines and shard subsets.

## Record (`sample_XXXXXX.npz`)

| key | shape | content |
|---|---|---|
| `shape_xyz` | (n, 3) float32 | 3D patch vertices, mm, random rigid pose and patient-size scale |
| `faces` | (m, 3) int32 | triangles, consistently oriented, single boundary loop |
| `boundary_loop` | (k,) int32 | ordered boundary vertex ids (suture line) |
| `boundary_resampled` | (128, 3) float32 | suture line resampled by arclength (start = loop[0]) |
| `arap_uv` | (n, 2) float32 | **label**: ARAP template (mm), per vertex |
| `arap_outline` | (128, 2) float32 | ARAP template boundary, same arclength parameters as `boundary_resampled` |
| `lscm_uv` | (n, 2) float32 | LSCM template (what the Baffle Planner computes today), per vertex |
| `vertex_stretch_s1`, `vertex_stretch_s2` | (n,) float32 | principal stretches of the ARAP map, vertex-averaged |
| `vertex_gauss_curvature` | (n,) float32 | Gaussian curvature estimate (1/mm^2) |
| `vertex_angle_defect` | (n,) float32 | integrated curvature per vertex (rad); boundary: pi - angle sum |
| `inflated_xyz_m{i}_p{j}` | (n, 3) float32 | physics shards only: equilibrium of the ARAP template sewn on the suture line, material i, pressure j |
| `meta` | JSON string | `family`, generator `params`, `metrics` (all `distortion_metrics` keys), `darts`, `pressure_mmhg`, `material`, `inflate_converged` |

Families: `tunnel` (swept DORV/PAPVR tunnels, optional bulge), `tps` (Baffle-Planner thin-plate
spline baffles with surface points), `trouser` (Mustard-type, skewed), `cap` (domes). Sizes
20-90 mm after the 0.7-1.6 scale; mesh edge length 0.75-1.3 mm; 300-6000 vertices.

Physics grid: pressures 15 and 30 mmHg; materials `pericardium_like` (StVK E=10 MPa, nu=0.3,
t=0.3 mm) and `eptfe_like` (E=40 MPa, nu=0.3, t=0.4 mm). These are placeholders, not measured
properties; they bracket the stiffness range and must be replaced by fitted data before any
clinical use.

## What the labels are good for

* `arap_uv` / `arap_outline`: the target of a flattening surrogate (level 1). The outline is what
  gets cut; `arap_uv` allows per-vertex (mesh-aware) models.
* `lscm_uv`: a second solver's answer; the LSCM-vs-ARAP difference (0.22 mm RMS on the outline)
  is the accuracy a surrogate must reach to be "as good as a method".
* `metrics.boundary_cumulative_mismatch_mm`, `darts`, `vertex_angle_defect`: triage targets
  (does this baffle need darts, where).
* `inflated_xyz_*`: forward physics labels (template + pressure + material -> 3D). The inverse
  direction (loaded 3D -> template) is the valuable surrogate; with these records it can be
  trained as (inflated_xyz, pressure, material) -> arap_uv, since the ARAP template is by
  construction the one that produced the inflated state. Note this makes the ARAP template the
  "least-strain" design only approximately; Report 3 explains the strain criterion.

## Known limitations

* Synthetic shapes only; the clinical distribution is unknown until `clinical_baffles/` fills up.
* Material properties are placeholders; suture uptake and the collapsed intra-operative state are
  not modelled.
* Labels are solver outputs, so a supervised model cannot exceed them (Report 4).
